## zeroid-세로형 · zeroid-가로형

무신사 입점 제안서를 세로형과 가로형 두 가지로 만들었습니다. 두 폴더 모두 11.02 고정본입니다.

- `index.html`: 제안서 페이지. 브라우저로 열면 됩니다
- `*.pdf`: 같은 제안서의 PDF
- 나머지 이미지 파일은 제안서에 들어가는 제품 사진과 캐릭터입니다

## saltware-blog

유튜브 영상 [클로드로 블로그 에이전트 팀을 만들었습니다](https://www.youtube.com/watch?v=0ESZJFUZD-k) 방식을 따라 만든 블로그 작성 시스템입니다.

- `CLAUDE.md`, `.claude/agents/`: 리서치 → 글쓰기 → 이미지 → 조립 에이전트 4명과 팀장
- `guide/`: 스타일, SEO, 이미지 가이드와 솔트웨어 지식 파일
- `scripts/`: 이미지 캡처·템플릿, 사이트 생성 스크립트
- `output/`: 완성된 글 12편(데이터 한 스푼 3, 데이터 노트 4, 고객 사례 5)과 이미지. `guide-*` 폴더는 솔루션 가이드 5편의 그림만 먼저 들어 있습니다
- `index.html`, `contact.html`: 블로그 시안 화면
- `plan.html`: 기획 노트. 경쟁사 비교, 가설 퍼소나 4명, 고객여정지도(감정 곡선), 측정 계획

사이트 보기:

```bash
cd saltware-blog
py -3 -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다. 블로그는 과제용 시안이며 문의·구독 폼은 실제로 전송되지 않습니다.
