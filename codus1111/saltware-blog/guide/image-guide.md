# 이미지 가이드

이미지는 외부 AI 이미지 API를 쓰지 않는다.
매번 HTML과 CSS로 그림을 만들고 `scripts/capture.py`로 PNG로 캡처한다.

```
py -3 scripts/capture.py <html 파일> <png 파일> <가로> <세로>
```

## 1. 공통 규칙

- 솔트웨어 홈페이지(https://www.saltware.co.kr/assets/css/tokens.css) 색을 그대로 쓴다
- 따뜻한 베이지 바탕 + 오렌지 포인트 + 갈색 강조의 톤온톤. 다른 계열 색(파랑, 초록 등)은 쓰지 않는다
- 색은 아래만 쓴다

| 이름 | 색 | 쓰임 |
|---|---|---|
| 베이지 | #F4F2EA | 이미지 배경 |
| 연베이지 | #F8F6F1 | 넓은 띠 배경 |
| 흰색 | #FFFFFF | 카드 |
| 연오렌지 | #FFF3E2 | 강조 카드 배경 |
| 오렌지 | #E8811A | 막대, 테두리, 선 같은 포인트 (글자에는 쓰지 않음) |
| 갈색 | #895118 | 강조 글자, 강조 동그라미 |
| 먹색 | #292723 | 제목, 배지 바탕 |
| 글자 | #141413 / #45423C | 본문 / 보조 글자 |
| 선 | #DEDACD | 구분선, 연결선 |

- 오렌지 바탕에 흰 글씨는 잘 안 읽힌다. 배지는 먹색 바탕 + 연오렌지 글씨로
- 글꼴: `'Pretendard', 'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif`
- 이미지 속 글자는 짧게. 한 줄에 15자 이내, 한 장에 문장 4개 이내
- 글자가 테두리 밖으로 나가거나 잘리면 안 된다
- 모든 이미지 오른쪽 아래에 작게 `SALTWARE` 표시 (#292723, 투명도 0.5)

## 2. 썸네일

- 크기 1200 × 675
- 왼쪽 위에 시리즈명 배지 (먹색 바탕, 연오렌지 글자)
- 제목 위에 오렌지 막대 하나
- 가운데에 글 제목을 두 줄 이내로. 크게(56px 이상), 굵게
- 아래에 부제나 핵심 한 줄 (24px 안팎)

## 3. 본문 이미지 템플릿 4종

크기는 모두 1080 × 720.

| 템플릿 | 언제 쓰나 | 모양 |
|---|---|---|
| 비교표 | 두세 가지를 견줄 때 | 2~3열 카드. 열마다 제목 + 특징 3줄 |
| 단계 흐름도 | 순서가 있는 과정 | 동그란 번호 + 상자 3~4개가 가로로 이어짐 |
| 핵심 카드 | 꼭 기억할 것 3가지 | 세로로 쌓인 카드 3장. 카드마다 굵은 제목 + 한 줄 설명 |
| 강조 문구 | 글의 핵심 문장 하나 | 가운데 큰 따옴표와 문장 하나, 아래 작은 출처나 설명 |

## 4. 검수

캡처한 뒤 PNG를 직접 열어 보고 확인한다.
- 글자가 잘리거나 넘치지 않았는지
- 여백이 한쪽으로 쏠리지 않았는지
- 요소가 비뚤어지지 않았는지
문제가 있으면 HTML을 고쳐 다시 캡처한다. 문제가 없어질 때까지 반복한다.
